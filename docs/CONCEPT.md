# にゃるほど コンセプトドキュメント v2.0

> 「毎日のひとコマが、この子の物語になる。」

## アプリの定義
猫と暮らす毎日の「点」——1枚の写真、ごはんの記録、ちょっとした変化——が、時間とともに「線」になり、やがて1匹の猫の物語になるアプリ。

## コア体験ループ
1. **点を打つ** — 写真を撮る、ケアを記録する
2. **意味が生まれる** — 猫を識別し分類する（裏側で静かに）
3. **線がつながる** — 成長の軌跡・季節の変化・生活リズムになる
4. **物語が見える** — Discover、週次ハイライト、変化のレポートが届く

## プロダクト原則
- **「うちの子」が主語**: 「ペット管理」ではなく「この子の思い出を残す」
- **AIは黒子**: ユーザーが感じるのは「勝手に整理されている」体験
- **軽い入力、豊かな出力**: ユーザーがするのは撮影とタップだけ
- **継続が価値**: 1日=写真、1週間=アルバム、1年=かけがえのない物語

## 機能優先度
| 層 | 機能 | 役割 |
|---|---|---|
| ★ コア | 写真コレクション | 「ひとコマ」を積み重ねる器 |
| ★ コア | 自動認識・分類 | 物語を育てるエンジン（AIを表に出さない） |
| ○ サポート | 家族共有・ケアログ | 物語を家族で育てる仕組み |
| ○ サポート | 通知・リマインダー | 物語を続けさせる仕掛け |
| △ 後期 | 足跡・ポイント経済 | ゲーミフィケーション |
