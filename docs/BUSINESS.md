# にゃるほど 事業性分析・収益化方針書

作成日: 2026-03-21

## 1. 率直な評価

### 1-1. 可能性はあるか？

**条件付きでYES。**

ペットテック市場は成長中（年平均15-20%）、猫飼育頭数は犬を上回り微増傾向、不況耐性も高い。
ただし「写真整理アプリ」として勝負するなら不可能。Google Photos / Apple Photosが無料で提供している。

にゃるほどが成立する唯一のポジションは **「時間の価値化」** ——記録が積み重なって物語に変わる体験。これはGoogle Photosにもinstagramにもない。

### 1-2. やめるべきシグナル

以下のいずれかに該当するなら、撤退を検討すべき。

- Phase 1 リリース後3ヶ月で、1週間以上継続利用するユーザーが10人未満
- 「物語」系機能（週次ハイライト・1年前の今日）にユーザーが反応しない
- AI処理コストが月5万円を超えても有料ユーザーが0人
- 自分自身がこのアプリを毎日使いたいと思えなくなった

### 1-3. 続けるべきシグナル

- ユーザーが「図鑑を埋めたい」「もっと写真を追加したい」と能動的に使う
- 週次ハイライトや1年前通知のスクリーンショットがSNSでシェアされる
- 「有料でもいいから○○がほしい」というフィードバックが来る

## 2. 競合分析

| 競合 | 強み | 弱み | にゃるほどとの距離 |
|------|------|------|-------------------|
| **Google Photos** | 無料、AI分類、無限ストレージ | 猫特化でない、物語化しない | 写真整理では勝てない。物語化で差別化 |
| **ねこノート** | 猫特化、健康記録 | 写真中心でない、AI活用なし | ケア記録は被るがコア体験が違う |
| **11pets** | 多頭管理、獣医連携 | 実用重視、感情的価値が薄い | 「管理」vs「物語」で棲み分け可能 |
| **Instagram** | 無料、SNS効果、コミュニティ | 時系列管理弱い、猫特化でない | 「他人に見せる」vs「自分のために残す」 |
| **猫カメラ系アプリ** | 撮影に特化、フィルター | 蓄積・振り返り機能なし | 単発vs継続で差別化 |

**にゃるほどの唯一のポジション:**
「撮って→貯まって→物語になる」の一気通貫体験。撮影特化でもSNSでも健康管理でもない、「時間の価値化」アプリ。

## 3. 収益モデルの選択肢

### 3-A. フリーミアム + サブスクリプション（推奨）

| 項目 | 無料プラン | プレミアム（月額480〜980円） |
|------|-----------|--------------------------|
| 写真登録 | 月30枚まで | 無制限 |
| AI自動分類 | 月10枚まで | 無制限 |
| 図鑑 | 基本軸のみ | 全軸開放 |
| 週次ハイライト | テキストのみ | 写真付きアルバム生成 |
| 1年前の今日 | × | ○ |
| 成長レポート | × | 月次・年次レポート |
| 家族共有 | 2人まで | 5人まで |
| 猫の登録 | 1匹 | 無制限 |
| データエクスポート | × | ○ |

**なぜこのモデルか:**
- 「使い続けるほど価値が増す」コンセプトとサブスクの相性が極めて良い
- 無料で価値を体験→データが貯まる→やめられなくなる→有料転換、という自然な導線
- 写真データのロックインが解約抑止力になる

### 3-B. 代替/補助的な収益源

| 収益源 | 可能性 | 優先度 | 備考 |
|--------|--------|--------|------|
| 思い出フォトブック生成（都度課金） | 高 | Phase 2 | 物理商品との連携。1冊2,000〜3,000円 |
| プレミアム図鑑テーマ（買い切り） | 中 | Phase 2 | 季節限定テーマ等 |
| 獣医/ペット保険への送客（アフィリエイト） | 中 | Phase 3 | ケアログデータを活かす |
| 広告 | 低 | 非推奨 | コンセプト（うちの子の物語）と広告は相性が悪い |

## 5. コンセプト段階で決めておくべき12のこと

### プロダクト判断

1. **無料で十分に価値がある体験は何か？**
   → 写真の自動分類と基本図鑑。これだけで「うちの子を見つけてくれる」体験ができること。

2. **お金を払う理由は何か？**
   → 「時間の価値化」機能。週次ハイライト、1年前の今日、成長レポート。過去が豊かになる体験。

3. **無料→有料の転換ポイントはどこか？**
   → 利用開始1ヶ月後。図鑑がある程度埋まり、「もっと見たい」「振り返りたい」と思った瞬間。

4. **データのポータビリティをどうするか？**
   → エクスポート機能はプレミアム限定。ただしGDPR対応でデータ削除リクエストには応じる。

### 技術判断

5. **AI処理コストをどう制御するか？**
   → 無料枠にAI処理の月間上限を設ける。バッチ処理で効率化。低コストモデル（gpt-4o-mini）優先。

6. **PWAのまま収益化できるか、ネイティブ必須か？**
   → PWAのままでもStripe経由のWebサブスクは可能。ただしApp Store経由のほうが信頼性・発見性が高い。PWAで検証→有料ユーザーが10人超えたらネイティブ化検討。

7. **写真ストレージの上限と圧縮戦略は？**
   → サムネイル（表示用）+ 圧縮原本（保存用）の2段構え。無料枠はストレージ上限500MBなど。

### 事業判断

8. **いつまでにいくら稼げなければ撤退するか？**
   → Phase 1リリースから6ヶ月で有料ユーザー10人未満なら、事業としては見込みなしと判断。趣味プロジェクトとして続けるか撤退。

9. **自分の時間コストをどう考えるか？**
   → 一人開発で月100時間以上投入するなら、最低でも月5万円の収益がないと持続不可能。いつまでに到達したいか決める。

10. **法人化のタイミングは？**
    → 年間収益が20万円を超えたら確定申告必須。50万円/年を超えたら個人事業主登録を検討。

### マーケティング判断

11. **最初のユーザー100人をどう獲得するか？**
    → 猫飼い主コミュニティ（Twitter/X、猫ブログ、猫カフェ）でのベータテスト招待。「うちの子の写真が図鑑になる」という体験をスクリーンショットでシェアしてもらう。

12. **App Storeでの説明文の核は何か？**
    → 「毎日のひとコマが、この子の物語になる。」をそのまま使う。スクリーンショットは「Before（カメラロールの猫写真の山）→ After（美しい図鑑と物語）」の比較。

## 8. 最終判断のフレームワーク

このプロジェクトを続けるかどうかは、最終的に3つの問いに集約されます。

**Q1. 自分自身がこのアプリの最初のヘビーユーザーになれるか？**
→ 自分が使わないものを他人に売ることはできない。

**Q2. 「有料でもいいから続けたい」とユーザーが言う瞬間を作れるか？**
→ その瞬間は「時間が経ったあとの振り返り」にある。初回の感動ではなく、3ヶ月後・1年後の感動。

**Q3. 6ヶ月後に「やってよかった」と思える状態を定義できるか？**
→ それが収益であれ、学びであれ、ポートフォリオであれ。ゼロにはならないプロジェクトにする。
