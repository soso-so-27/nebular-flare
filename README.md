# にゃるほど

> 毎日のひとコマが、この子の物語になる。

猫と暮らす毎日の「点」が、時間とともに「線」になり、やがて1匹の猫の物語になるアプリ。

## テックスタック
- Next.js 16 (App Router) / TypeScript / React 19
- Tailwind CSS 4 / Radix UI / Framer Motion
- Supabase (PostgreSQL + Storage)
- OpenAI API / Firebase Cloud Messaging
- Vercel

## 開発
npm install
npm run dev

## ドキュメント
- `docs/CONCEPT.md` — コンセプトドキュメント
- `docs/TRIAGE.md` — 残す/捨てる判断表
- `docs/BUSINESS.md` — 事業性分析
